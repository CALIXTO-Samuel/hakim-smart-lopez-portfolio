# Hakim Smart Lopez — Portfolio

**Um espaço para apresentar ideias, projetos e possibilidades.**

Portfólio fictício de Hakim Smart Lopez, empreendedor e cofundador da HSL Technologies, uma startup criada em Belo Horizonte, Minas Gerais.

O projeto apresenta sua trajetória, a história da empresa, sua equipe e alguns dos projetos desenvolvidos.

## Sobre o projeto

O site foi desenvolvido como um exercício de criação de páginas web, utilizando HTML5 e CSS3. A proposta foi construir uma apresentação profissional, com identidade visual própria, navegação simples e adaptação para diferentes tamanhos de tela.

## Páginas

- **Início:** apresentação de Hakim e da HSL Technologies.
- **Sobre:** trajetória, equipe, história da empresa e projetos.
- **Contato:** formulário demonstrativo com validação nativa do navegador.

## Projeto em destaque

### ELION

O primeiro grande projeto da HSL Technologies é um ecossistema tecnológico que reúne:

- Sistema operacional próprio;
- Inteligência artificial;
- Cibersegurança;
- Ferramentas de produtividade;
- Computação em nuvem.

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — identidade visual, estilização e responsividade.
- GitHub — hospedagem do código e publicação do site com GitHub Pages.
